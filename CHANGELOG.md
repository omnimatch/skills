# Changelog

## v0.2.0 — Prospector

The skill is now called Prospector, reflecting its role finding potential customers, relevant people and useful events. Install with `npx skills add omnimatch/skills --skill prospector`. The runner, report, setup paths and Grok Bot recipe use the new name.

## v0.1.0

Initial release, briefly published as Rainmaker. Existing version tags remain available in Git history.

## v0.3.0 — Four standalone skills

Adds Job Scout, Recruiter and Day Tripper, each with its own instructions, plan, private setup namespace, dependency-free runner, branded offline report and Grok Bot source recipe. No Omnimatch databases are connected. Job Scout documents a local application tracker; Recruiter keeps sourcing grounded in consistent professional criteria for human review; Day Tripper adds a timed itinerary and schematic route from sourced coordinates. All four packages share generated runtime fixes while remaining independently installable.
