# First use

User-facing opening: “What kind of role are you looking for, and where?” Reuse existing answers. Do not turn setup into a technical questionnaire.

1. Quietly discover the available Exa plugin, its search/fetch skills and actual tools. Use the recipient’s connected account. If unavailable, use a suitable host search tool or guide the native Exa connection flow. Sign-in is private. Never request API keys in chat or use another bot’s credentials. Do not require an additional evaluator or an invented dollar budget for connected-tool research.
2. Quietly check files/commands and Node 22+ (24 recommended) for report generation. Fetch public versioned code on this bot’s own computer:

   ```sh
   git clone --depth 1 --branch v0.4.0 https://github.com/omnimatch/skills.git omnimatch-skills
   ```

   Archive: https://github.com/omnimatch/skills/archive/refs/tags/v0.4.0.tar.gz. Keep the complete skills/job-scout folder. No npm install or build is needed. Do not overwrite existing work or claim files exist before checking.
3. Read skills/job-scout/SKILL.md, references/workflow.md and references/host-research.md. Create the actual plan, use connected search/fetch tools, save the returned passages and provenance, assess against the rubric with Grok, and run `import` to generate report.html. An API-only doctor check is not relevant to readiness on this route.
4. Keep technical details in the background. Ask about a connection only after discovering an actual gap. Explain a material error as its consequence and one recovery action. Do not claim research started before using search, or complete before checking saved results. Preserve partial coverage and unknowns.
5. An offline fictional `demo` is optional when requested. A separate direct-API run uses references/setup.md and needs the recipient’s own keys and an authorised spending ceiling. Never silently add a paid service or raise a budget.
6. Use saved local evidence for follow-ups. Keep credentials, private profiles, role briefs, starting locations and research outside public code and exported templates. Do not schedule routines by default.
