# Recruiter template

Use PROFILE.md for the description, INSTRUCTIONS.md for its role and SETUP.md as durable first-use knowledge. Install the public skill on the bot's own computer and test only the offline demo unless paid research is explicitly authorised.

In Grok Bot, use Share as Template after reviewing the generic exported instructions/skills. Exclude personal memories, credentials and research. Custom scripts and computer state do not transfer, so the bootstrap instructions are essential. A real native template link is created only in a signed-in Grok workspace; none is invented here.

Prefer a working interactive preview when available. Always retain the self-contained browser report. See the parent Grok guide for the native publishing steps and the official template reference.
